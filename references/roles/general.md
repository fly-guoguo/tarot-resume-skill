# 岗位族：通用兜底 / 实习 / 职能 (General)

Use for：尚无专属 profile 的岗位（设计、财务、法务、行政、教培、医疗、供应链、项目经理/PMO 等）、在校实习生、应届生、或识别未收敛时。对话中一旦看清具体行业，用该行业真实业务语境调味，保持本族六维框架。

## 1. Q1 常见模块分流（Core vs Routine）
- **高含金量主角盘（优先深挖）**：跨部门卡点推动、流程/制度从混乱变清晰、重要活动/专项节点保障、替团队做出可复用模板/工具、或老板最放心只交给你的核心环节。
- **常规盘（精炼 1 行）**：日常例行事务、基础文档/数据维护。

## 2. Q2 六维通用量化弹药库 + 倒推公式

*每次只挑最贴合该摊事的 2–3 维提示，绝不六个全砸给用户。*

| 维度 | 编号量级选项 | 没统计过时怎么倒推 |
|---|---|---|
| 数量（件/单/篇/场/份） | ①个位数 ②几十 ③上百 ④上千 | 每周/每月处理频次 × 任职月数 |
| 时间效率（省时/提前） | ①每次省小时级 ②周期缩短天级 ③周级 | 优化前做一次要多久 vs 优化后要多久 |
| 覆盖范围（人/部门/门店） | ①单团队 ②跨 3+ 部门 ③全公司 ④对外客户 | 这件事实际服务了多少同事/门店/客户 |
| 准确率与零差错 | ①零延期/零重大失误 ②差错率降半 ③99%+ | 高压/高频交付下的稳定度记录 |
| 金钱（省钱/控费/经手） | ①千级 ②万级 ③十万级 ④百万+ | 经手预算规模、比价省下的采购差额 |
| 协同与人数 | ①5 人内 ②十几人 ③几十人 ④上百人 | 统筹对接的上下游角色与人数 |

## 3. 反差痛点 & 下游传导话术
- **反差开路**：「如果你不管这摊事，或者按以前的老办法干，团队里最容易出什么岔子、最费谁的时间？」
- **下游传导**：「你把这事理顺/做完之后，哪个部门或哪位同事最明显地松了一口气？有没有沉淀成表格/SOP，后来新人直接照着就能用？」

## 4. Q3 高段位方案权衡（Decision）追问
- **约束破局**：「时间紧、没权限、跨部门不配合时，你是怎么把事推着落地的？」
- **多走半步**：「同样做这件事，普通人交差就结束了——你当时额外多想了哪一步，把隐患提前堵住了？」

## 5. 输出强动词与实习生诚实 Framing
- **通用强动词**：统筹、梳理重构、推动落地、排查堵漏、沉淀 SOP、精准保障、独立承接。
- **实习生特别原则**：诚实反而最加分！重点突出**上手速度、执行零差错可靠性、具体承接的模块量级、替导师/团队分担的具体环节**；动词严格停在「独立承接某模块 / 协助完成 / 执行落地」，绝不硬拔成「主导整体战略」。

## 6. 面试防御杀招（防翻车）
- **日常职责包装成重大项目**：清晰切分「日常保障」和「专项改进」，别把每周例会写成“主导跨部门沟通项目”。
- **实习生过度拔高**：被追问全局背景容易露馅，守住自己真实负责的一亩三分地并讲深讲透最稳。
- **敏感信息**：涉及财务、薪酬、内部纠纷或未公开项目，主动提供匿名与脱敏写法。
