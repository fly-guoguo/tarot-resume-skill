# 岗位族：销售 / 商务 / BD (Sales)

Covers：销售、客户经理（AM）、KA/大客户销售、渠道销售、BD/商务拓展、售前（偏商务）、客户成功（CSM）、销售实习。
> **管理向切换**：若内容偏带销售团队，量化维度切换到「团队人数、整体 Quota 达成率、新人开单周期、大单陪谈胜率」。

## 1. Q1 常见模块分流（Core vs Routine）
- **高含金量主角盘（优先深挖）**：标杆 KA 大客户从 0 破冰或竞品手中撬单、超额业绩与大额回款攻坚、核心生态渠道体系搭建、高价值老客续费/增购（Upsell）盘活。
- **常规盘（精炼 1 行）**：日常 CRM 录入、常规客户回访、例行线索跟进。

## 2. Q2 量化维度弹药库 + 倒推公式

| 维度 | 编号量级选项 | 没统计过时怎么倒推 |
|---|---|---|
| 金额（签约/回款/ARR） | ①10万内 ②10–50万 ③50–200万 ④200万+ | 平均客单价 × 成交单数（**签约额与实际回款必须分清口径**） |
| 业绩达成率 / 团队排名 | ①100% 达标 ②超额 20%+ ③团队 Top 3 / 销冠 | 实际完成额 ÷ 考核 Quota；全组多少人排第几 |
| 客户体量与层级 | ①几个标杆 KA ②几十家 SMB ③上百客户盘子 | 区分头部标杆大客户（带行业地位）vs 常规腰部客户 |
| 成单周期缩减 | ①周级 ②月级 ③比均值缩短 30%+ | 公司平均签单周期 vs 你最快/平均签单周期 |
| 续费 / 增购 / 转介绍 | ①续费率 85%+ ②增购翻倍 ③老带新占 X% | 续费客户数 ÷ 到期客户数；增购金额占总盘比例 |

## 3. 反差痛点 & 下游传导话术
- **反差开路**：「你接手这个区域/大客户盘子时，原本是什么局面？空白市场没人认、被强竞品占死、还是老客投诉不断准备流失？」
- **下游传导**：「签下这个标杆客户 / 搭好这套渠道之后，除了当季业绩，**对公司还有什么长尾杠杆？** 比如帮后续同类行业打出了标杆案例、缩短了团队成单周期，还是形成了稳定年度复购？」

## 4. Q3 高段位方案权衡（Decision）追问
- **死局破冰招法**：「客户原本价格嫌贵 / 预算冻结 / 用着竞品不想换，**你没靠无底线降价，而是用了什么切口把局破开的？**（比如替客户算停机损失账、拉技术做 POC 试点、找准真正决策链关键人？）」
- **多方拉通**：售前、产品、交付或老板各帮了什么忙？**哪一步谈判卡点是你自己扛下来逆转的？**

## 5. 输出强动词与黄金范例
- **强动词**：从 0 破冰、竞品撬单、主导谈判、挽回流失、深耕增购、搭建渠道、超额交付。
- **范例**：「针对被竞品占领半年的区域 Top 3 制造客户，放弃单纯拼低价，通过联合售前测算旧系统停机隐性成本并设计 2 周小范围 POC 验证，独立推进 3 轮高层谈判重新签约 80 万+（全额回款），此后连续 2 年稳定复购并带来 2 家同业转介绍。」

## 6. 面试防御杀招（防翻车）
- **签约额 ≠ 回款额**：面试官最怕遇到只签意向合同不回款的“虚胖业绩”，必须提前写清/备好回款口径。
- **团队业绩 vs 个人贡献**：明确个人独立开发份额，以及公司分配线索 vs 自主开拓的比例。
- **区域范围空洞**：只写「负责华南区」没有盘子大小，必补行业、客户数或年度指标规模。
