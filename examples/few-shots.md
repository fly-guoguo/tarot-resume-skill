# Few-Shot 对话示范 (Value-Transmission Probing)

两个完整示范，展示「三问 × 价值传导链」的真实对话节奏：**一次一题、主角深挖/配角精炼、反差与下游传导、没数字就倒推量级、Q3 挖方案权衡与沉淀资产**。学节奏与提问角度，不照搬内容。

---

## Example A — AI 视频创作平台 · 产品运营（深度传导全流程，虚构示范案例）

**Step 0 · 极简开场**
skill：「抽第一张牌前，先报个简短家门：哪家公司（可匿名）、什么岗位、起止年月（如 2024.09–至今）？心里有想投的方向也可以顺带一句。」
user：「可灵 AI，产品运营，负责创作者生态和增长，2024年9月到现在。后面想看 AI 应用产品运营或者增长产品经理。」
→ `archive.basic = {可灵 AI, 产品运营（创作者生态与增长）, 2024.09–至今, targetRole: "AI 应用产品运营 / 增长产品经理"}`

**Q1 · 魔术师（职责版图 + 主角分流）**
skill：「第一张牌是**魔术师**。不用写得像岗位说明书——大白话聊聊，你平时主要扛哪 3–5 摊事？顺手点一下：**哪 1–2 摊最耗心血、最能代表你的段位？**」
user：「大概五摊：创作者分层与模板冷启动、AI 短片创作大赛与社媒破圈增长、大版本发版与社区 Badcase 反馈闭环、商业化积分促活活动，还有核心转化漏斗数据看板。最耗心血的是新客模板冷启动和 AI 创作大赛破圈这两摊。」
→ `roleFamily = operations`（兼顾产品增长视角）；
→ `workItems = [w1 创作者分层与模板冷启动(core), w2 AI 创作大赛与社媒破圈(core), w3 发版反馈闭环(routine), w4 商业化积分活动(routine), w5 核心漏斗看板(routine)]`

**Q1 版图透视（客观不空吹，点出业务杠杆位）**
skill：「魔术师看到了你的版图：5 摊事，但真正让你拉开身位的是一个**产品×增长传导杠杆位**——你既在前端把高门槛的模型能力翻译成小白秒上手的模板体验，又在外部把创作者样片撬动成全网破圈声量，正好切中你要投的 AI 增长产品方向。接下来我们把 80% 火力砸在 **『模板冷启动』** 和 **『AI 创作大赛』** 这两摊主角上，其余三摊一句带过。」

**Q2 · 正义（天平称重：反差 → 量化与下游传导 → 口径/归因防御）**
skill：「第二张牌是**正义**，左盘放投入，右盘称价值。先看主角第一摊 **『创作者分层与模板冷启动』**——在你搭这套模板库和冷启动流之前，新用户进来原本卡在哪、有多痛？」*(反差基线探针，不是干问“有什么数字”)*
user：「以前新用户注册完对着空白 Prompt 输入框根本不知道怎么写，生成两次全是废片就流失了，首日出片率长期卡在 22% 左右。」
→ `w1.baseline` 填充（反差立刻立住！）

skill：「太扎心也太典型了——空白输入框劝退小白。那你做完之后，**沉淀了多少模板、首日出片率拉到了多少？** 往后端看，有没有直接传导到留存或付费？」*(量化交付 + 下游传导)*
user：「我主导梳理了 300+ 高复用场景模板和一键同款流，上线后新用户首日出片率从 22% 提到了 41%，而且直接带动会员首充转化率涨了 6.5pp。」
→ `w1.results / transmission / value` 填充；`metricsLibrary` 更新

skill：「22% 到 41% 加首充 +6.5pp 非常硬！正义牌帮你提前护两道面试防线：**这个 41% 的分母口径是什么**（比如首日完成至少 1 次有效生成占比），以及**怎么证明不是同期模型画质升级带来的自然涨幅？**」*(口径与归因防御探针，1 轮收尾)*
user：「口径是首日完成至少 1 次有效视频生成占比；而且当时是跑的同周期 A/B 实验对照验证，剥离了大盘自然涨幅。」
→ `w1` 六维全满！

skill：「漂亮，有 A/B 对照面试官就挑不出毛病。再快速过一眼第二摊主角 **『AI 创作大赛与社媒破圈』**——以前社区样片痛点是什么，你操盘后交出了什么量级、帮产品后端沉淀了什么资产？」
user：「早期社区样片太同质化、社媒全在凑热闹尝鲜。我操盘了 3 期主题创作赛加小红书/B站 KOC 矩阵，累计征集优质投稿 1.2万+ 件、全网自然曝光 8000万+，沉淀出 Top 200 签约核心创作者池，直接反哺首页精选流和海外官宣素材库。」
→ `w2` 六维全满！

skill：「剩下三摊常规盘（发版反馈闭环、积分促活活动、漏斗看板）咱们不展开拷打，一句话顺手带过交付物就行（没数字也没关系）。」*(配角快速过，不消耗用户耐心)*
user：「发版反馈每月整理 40+ 高频生成痛点单，推动运镜控制和首尾帧功能排期；商业化活动推动节假日积分消耗，具体 ROI 忘了；漏斗看板定位出图生视频排队超时流失卡点，推了队列提示和高优通道。」
→ `w3/w4/w5` 精炼归档，不强凑数字。

**Q3 · 星币首牌 OFFER（王牌之战：高能触发 → 方案权衡 → 战果与沉淀）**
skill：「第三张牌是**星币首牌**——帮你敲开 Offer 之门的那一战。挑一件**最能代表你段位的硬仗**（从 0 到 1 摸出来的、资源受限硬啃下来的、或解了死结的事），像讲故事一样随口说说？」
user：「就讲『一键同款』新客首单出片破局项目。当时新模型发版涌进来一大波小白流量，写不出 Prompt 生成两次不满意就永久流失了，我联合设计推了爆款样片一键同款，实验组首日出片率从 22% 涨到 41%，次留涨了 8.4pp。」
→ `p1` 的 `S / R` 雏形已现；锁定最拉段位的缺口：`decision`（方案权衡：为什么选一键同款？）+ `own` + `asset`。

skill：「数据非常亮眼！不过面试官最想听的是你的判断力——**面对小白不会写 Prompt 的死局，常见做法要么做一套详细的『Prompt 教学学院』，要么发算力优惠券拉留存；你当时为什么拍板放弃这些常规套路，硬推『一键同款』？哪几步离了你真转不动？**」*(方案权衡探针)*
user：「当时研发排期全满根本拿不到大改版资源，而且小白压根没耐心看教程、发券只换来羊毛党。所以我拍板走最轻量的『爆款样片反向拆参 + 一键复用』，自己亲手筛定首批 300+ 高成功率模板，拉通算法配好兜底参数，并主导推进 2 轮 A/B 灰度验证。」
→ `p1.decision / hard / own` 全部点亮！

skill：「『排期受限 + 教程反人性 → 反向拆参一键复用 + 兜底参数』，这个产品判断力太加分了！最后收官两件事：实验组和对照组的**付费率净差值**手头有数吗？另外打完这一仗，有没有留下**你明天走了还在继续运转的可复用机制**？」
user：「实验组付费率净差值具体小数忘了，先留待补充我回去查报表。机制上沉淀了一套『爆款样片自动入库 → 按复用率优胜劣汰』的运营 SOP 和模板评级标准，后面几个大版本冷启动都在直接复用。」
→ `p1.R` 诚实保留 `【待补充：实验组与对照组付费率差值】`，`p1.asset` 填充；询问是否再加项目 → 用户说「先这一个，出稿吧」。

**Output（严格基于档案，防编造自检通过）**
> **你的职场定位**：懂 AI 产品特性的增长型运营中枢——擅长在研发资源受限下，把高门槛模型能力翻译成低摩擦用户增长链路。

- **区块一 · 工作经历**：`可灵 AI · 产品运营（创作者生态与增长） · 2024.09–至今`
  - **【主角】** 针对新用户面对空白 Prompt 输入框导致首日出片率长期卡在 22% 的流失痛点，独立主导搭建 300+ 高复用场景模板库与「一键同款」冷启动链路，通过同周期 A/B 实验验证将新客首日出片率提升至 41%（口径：首日完成至少 1 次有效视频生成占比），直接带动会员首充转化率提升 6.5pp。
  - **【主角】** 针对早期社区样片同质化与外部自然破圈乏力问题，操盘 3 期主题 AI 短片创作赛及小红书/B站 KOC 矩阵，累计沉淀优质投稿 1.2万+ 件、撬动全网自然曝光 8000万+，签约沉淀 Top 200 核心创作者池并反哺产品首页精选流与海外官宣素材库。
  - **【常规精炼】** 承接大版本发版与用户反馈闭环，月均输出 40+ 高频生成痛点专题单并推动运镜控制、首尾帧功能落地；协同策划节假日商业化积分促活活动（【待补充：单次活动 ROI】）；搭建注册→生成→付费核心漏斗看板，定位图生视频排队超时卡点并推动高优通道引导优化。
- **区块二 · 代表性项目**：`「一键同款」新客首单出片破局项目 ｜ 独立主导`
  - **背景与卡点**：新模型发版涌入大量尝鲜流量，小白用户写不出高质量 Prompt 导致高废片率与永久流失，且研发排期极满拿不到重型改版资源。

- **量化成果库**：`300+ 场景模板` · `首日出片率 22% → 41%` · `会员首充 +6.5pp` · `投稿 1.2万+ 件` · `自然曝光 8000万+` · `次日留存 +8.4pp`

## Example B — 觉得自己「都在打杂、没数字」的社群运营（反差唤醒 + 倒推量级）

**Q1**
user：「小公司，用户运营，2024.07 到现在。每天就是维护微信群、写写公众号、偶尔做个活动，感觉没啥拿得出手的。」
→ `roleFamily = operations`; `workItems = [w1 社群维护, w2 公众号内容, w3 活动执行]`

**Q2（不逼问抽象数字，先用反差 + 倒推破冰）**
skill：「千万别小看这三摊——很多运营每天忙死，是因为没把『杂活』翻成业务账。我们先挑最花你时间的 **『微信群维护』**：如果按日常倒推一下，你手里大概管着**几个群、总人数在哪个档位**（①几百 ②几千 ③上万）？另外，你有没有做过哪件小事，让群里从冷清变热闹，或者替客服/销售省过事？」
user：「大概 12 个群，加起来 4000 多人吧。平时答疑特别多，后来我把高频问题整理成了自动回复和图文手册，客服那边问基础问题的工单少了一大半。」
→ 瞬间挖出：`w1` 规模 `12 个群 / 4000+ 用户` + 动作 `沉淀高频 FAQ 手册与自动回复` + 下游传导 `帮客服减少基础工单`！

skill：「你看，这哪是打杂——你直接帮客服挡掉了一大片重复工单！顺手确认一句：『少了一大半』你有大概数吗，还是咱们先诚实写『显著降低基础咨询工单，【待补充：下降比例】』？公众号那边如果不方便算数字，也可以直接跳过。」
user：「比例没统计过，先标待补充吧，直接帮我出稿。」
→ 尊重跳过，绝不编造！

**Output（节选）**
- 独立运营 12 个核心用户社群（覆盖 4000+ 用户），针对高频重复答疑痛点，主动沉淀标准图文手册并配置自动回复机制，有效分流基础咨询、减轻后端客服工单压力（降低比例【待补充：前后周均工单对比】）。
- 负责品牌公众号日常内容撰写与发布【待补充：月均更新篇数及篇均阅读量级】，协同落地日常用户活动。
- 缺口：基础客服工单下降比例（找客服同事要一下整理前后的周报）；公众号发文频次与阅读量（看公众号后台统计）。
