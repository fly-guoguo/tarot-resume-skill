# 三句话写简历 · 三问成历 (tarot-resume-skill)

> **在线体验（塔罗抽牌交互页）**：https://fly-guoguo.github.io/tarot-resume-skill/

一个以**深度价值传导**为核心的 Agent Skill + 配套塔罗交互营销体验页：以最终简历能打动面试官并经得起深挖为目标，用三个主问题沿着**「基线痛点 → 个人动作与权衡 → 量化交付 → 下游传导」**掘金一段职业经历，产出**工作经历 + 独立项目经历 + 成果库 + 缺口清单 + 面试防御**。

## 核心设计（v2.1 深度传导版）

- **三牌三阶（叙事与方法论统一）**：
  - **I · 魔术师（Q1 职责版图）**：盘点日常主战场与工具，自动区分**主角模块（Core，深挖）**与**日常模块（Routine，精炼 1 行）**，不平均用力。
  - **XI · 正义（Q2 价值称重）**：左盘投入痛点、右盘产出价值。用**反差法（接手前 vs 做完后）+ 下游传导（谁用了、撑了什么事）+ 量级倒推（没数据怎么诚实估算）**逐摊称重。
  - **星币首牌 · OFFER（Q3 王牌之战）**：挑出最能推开 Offer 之门的硬仗，深挖**卡点 → 方案权衡（为什么选 A 不选 B）→ 个人拐点 → 量化结果与沉淀资产**，多项目各自独立 STAR。
- **档案驱动（唯一事实源）**：全程维护结构化「工作经历档案」JSON，生成阶段只读档案，不把杂乱聊天记录灌给模型。
- **六大岗位弹药库**：内置 `招聘/人才智能`、`研发/算法`、`产品/AI产品`、`运营/增长/市场`、`销售/商务`、`通用/实习` 六套量化维度、量级选项、倒推公式与面试杀招。
- **绝不编造 + 面试防御**：每个数字必须溯源到用户原话或用户确认的倒推量级，缺失标 `【待补充：…】`；主动预判面试官高概率深挖口径。
- **时间与隐私规范**：任职起止年月统一 `YYYY.MM–YYYY.MM`（在职写「至今」）；支持全程公司匿名化。

## 安装与使用（Skill 核心资产）

纯文本协议（`SKILL.md` + `references/` + `examples/`），任何支持 Agent Skills 约定的宿主均可直接加载：

- **Claude Code**：将 `three-line-resume/` 复制到 `~/.claude/skills/`（全局）或项目 `.claude/skills/`。
- **Antigravity / DeepSeek Harness / 其他 Agent 宿主**：放入其 skills 挂载目录，确保 `SKILL.md` 位于根目录。

使用方式：直接对 Agent 说 **「帮我写简历经历」** 或 **「用三句话写简历」**。一次只聊一题，随时支持「跳过」「换个问法」或切换「速写版 / 深挖版」。

## 配套前端（web/ — 体验与展示入口）

单文件移动端 H5 [web/index.html](web/index.html)，黑白木刻塔罗美学，作为 Skill 的直观交互体验与传播演示页：

- **开箱体验**：直接打开 `web/index.html` 或部署到 GitHub Pages 即可；页面自动演绎 **18 张牌花式瀑布洗切 + 星尘消散**，用户可亲手从弧形扇面抽选三张牌，或点击右上角 **「▶ 演示」** 完整观摩虚拟案例（AI 视频平台产品运营）从口语输入 → 主角称重 → 方案权衡 → 双区块简历与面试防御的全过程。
- **与 Skill 深度对齐**：内置六大岗位族弹药库（含编号量级胶囊与快捷追问）、主角/常规分流、结果页支持**原地点击 `【待补充：…】` 补数升级**、全流程步骤可随时回退编辑。
- **BYOK 接入大模型**：点击左上角 `⚙` 填入 DeepSeek / MiniMax 或任何支持浏览器直连的 OpenAI 兼容接口（密钥以密码框输入、仅存本机浏览器 `localStorage`）。未填 Key 时也可使用完整的本地智能演示引擎。
- **牌图定制**：三张去水印精修木刻塔罗牌位于 `web/cards/`，亦支持 `?cards=3,1,2` 自定义牌序。

## 目录结构

```text
three-line-resume/
├── SKILL.md                      # 主协议：三牌深度传导流程 + 铁律 + 资源索引
├── README.md                     # 项目说明
├── references/
│   ├── archive-schema.md         # 工作经历档案 JSON 结构 v2.1（唯一事实源）
│   ├── questioning.md            # 深度价值传导追问引擎（六大探针 + 倒推法 + 卡壳话术）
│   ├── output-spec.md            # 双区块输出规范 + 防编造四步自检 + 精修协议
│   └── roles/
│       ├── recruiting.md         # 招聘 / 人才智能 / HR 中台
│       ├── engineering.md        # 研发 / 算法 / 数据工程 / 架构
│       ├── product.md            # 产品经理 / AI 产品 / 策略
│       ├── operations.md         # 运营 / 增长 / 市场 / 内容
│       ├── sales.md              # 销售 / KA / BD / 商务
│       └── general.md            # 通用兜底 / 实习 / 职能
├── examples/
│   └── few-shots.md              # 深度传导对话示范（复合岗 + 稀疏日常岗）
└── web/
    ├── index.html                # 移动端单文件前端（塔罗仪式感 + 深度对齐 + BYOK）
    └── cards/                    # 精修无水印复古羊皮纸木刻塔罗牌（card1~3.jpg）
```

## 扩展新岗位族

复制 `references/roles/general.md` 结构新增岗位档案（重点补齐量化维度、倒推公式、反差/下游传导话术与面试防御），在 `SKILL.md` 资源索引增加触发条件，并在 `web/index.html` 的 `ROLE_PROFILES` 中同步添加一组配置即可。

## 隐私说明

对话仅在宿主 Agent 或本机浏览器内运行，不向任何第三方收集或上传简历信息；支持公司与业务名匿名化。
